# Android Login Registration App

## 📱 Project Overview

Android Login Registration App is a simple Android application developed using Kotlin and XML in Android Studio.

This project demonstrates Activity navigation using Intent. The application contains a Registration Page and Login Page where the user can move from registration screen to login screen after submitting the form.

---

## ✨ Features

* User-friendly Registration Page
* Login Page UI
* Registration form with:

  * Username
  * Email
  * Password
* Login form with:

  * Username
  * Password
* Button click handling
* Navigation between activities using Intent
* Toast message implementation

---

## 🛠️ Technologies Used

* Kotlin Programming Language
